### 1. 查找完整的 Chrome 版本号

打开 Chrome 浏览器，在地址栏输入 `chrome://settings/help` 并回车，记录下你的完整版本号（例如：`148.0.7778.168`）。

### 2. 访问谷歌官方驱动发布页

直接点击访问现代 Chrome 驱动的官方仪表盘：
🔗 [Chrome for Testing availability](https://googlechromelabs.github.io/chrome-for-testing/)

### 3. 定位并下载 148 版本的驱动

* 直接点击顶部的 Stable 标签页，这个是稳定版
* 在页面中按 `Ctrl + F` 键，搜索你的前三位版本号：**`148.0.7778`**。
* 找到属于 `chromedriver` 这一行（**注意：别错选成 chrome**），在 `win64` 这一栏复制对应的 URL 链接。
* 将链接粘贴到浏览器新标签页回车，即可直接下载 `chromedriver-win64.zip` 压缩包。
*(注：如果页面里只有类似 `148.0.7778.150`，最后一位对不上完全没关系，大版本对上就能完美兼容)*

### 4. 解压并放置到指定项目路径

解压下载好的压缩包，把里面的 **`chromedriver.exe`** 提取出来，直接扔进你项目对应的配置文件夹中。确保最终的物理路径结构如下：

```text
你的项目根目录/
│
└─ res/
   └─ driver/
      └─ chromedriver.exe  <-- 放在这里

```
